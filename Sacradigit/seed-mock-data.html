Seed Mock Mass Intentions

Dev-only utility. Creates ~26 realistic sample intentions across three upcoming masses (plus a few unassigned ones) so you can see the Log, Reader's Sheet, and Find features working with real data. Every seeded record is tagged so it can be cleanly removed afterward.

What this creates: intentions across two upcoming Sunday masses and one Saturday anticipated mass, covering all five intention types, with a couple of recurring start/end-time tags so you can see that feature too.

Tagging: most donor names end in "(Demo)" so they're easy to spot in the Log tab. A handful use the demo parishioner login name exactly ("Maria P. Santos") so "My Intentions" on the user side has something to show too.

Cleanup: "Clear Mock Data" deletes exactly the records this tool created (tracked in this browser), not anything you've entered yourself.
